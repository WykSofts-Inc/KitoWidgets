# KitoWidgets

Home Screen and Lock Screen widget building blocks for SwiftUI, plus App Intents helpers. Part of
the [Kito](https://github.com/WykSofts-Inc/KitoDevKit) ecosystem.

## Installation

```swift
.package(url: "https://github.com/WykSofts-Inc/KitoWidgets.git", from: "0.1.0")
```
